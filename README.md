## 🧠 Microsoft IQ Integration
Eros decouples complex code security diagnostics by natively integrating with the **Microsoft Foundry IQ** intelligence layer and the **Foundry Toolbox**. Instead of linear prompting, it forces the LLM to follow a strict, multi-step clinical reasoning path before generating a response.

### Analysis Pipeline (Reasoning Phases)
1. **Phase 1: Syntax Check** — Validates abstract syntax tree (AST) integrity.
2. **Phase 2: Quality Review** — Evaluates PEP 8 compliance, naming, and type hints.
3. **Phase 3: Security Audit** — Scans for critical OWASP Top 10 vectors (e.g., CWE-89 SQL Injection).
4. **Phase 4: Performance Analysis** — Identifies database I/O and query bottlenecks.
5. **Phase 5: Refactoring** — Generates secure, parameterized code proposals with zero logical regression.

## 🚀 Quick Start & One-Click Deploy

Eros is fully optimized for fast execution and deployment using the Azure Developer CLI (`azd`).

### Local Simulation (3-Step Quick Run)
Clone the repository, install dependencies, and run the multi-step reasoning simulation in your terminal:
```bash
# 1. Clone the repository
git clone https://github.com && cd eros-code-analysis-agent

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the automated simulation script
python run_simulation.py
```

### ☁️ Cloud Deployment via Microsoft Foundry
Initialize and provision your agent infrastructure into your Azure environment instantly:
```bash
azd init --with-python
azd up
```
